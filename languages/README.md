# پوشه ترجمه‌ها (languages)

این پوشه محل قرارگیری فایل‌های ترجمه استاندارد وردپرس برای قالب **گروه هلدینگ آبیدر** است.

- دامنه متن (Text Domain): `abidar-group`
- مسیر اعلام‌شده در `style.css`: `Domain Path: /languages`

## ساخت فایل `.pot`

```bash
# با WP-CLI
wp i18n make-pot . languages/abidar-group.pot --domain=abidar-group

# یا با Poedit: File > New from POT > استخراج از پوشه قالب
```

## افزودن ترجمه

فایل `.po` را با نام محلی ترجمه کنید (نمونه: `abidar-group-fa_IR.po`)، آن را به `.mo` کامپایل کرده و در همین پوشه قرار دهید:

```bash
msgfmt abidar-group-fa_IR.po -o abidar-group-fa_IR.mo
```

> **نکته:** متن‌های رابط کاربری قالب از پیش به‌صورت فارسی نوشته شده‌اند و ترجمه انگلیسی/چینی از طریق
> **گروه آبیدر ← ۷. زبان‌های سایت** و دیکشنری داخلی انجام می‌شود. فایل‌های `.po/.mo` تنها برای
> ترجمه عبارت‌های ثابت وردپرس/المنتور و سفارشی‌سازی بیشتر کاربرد دارند.
